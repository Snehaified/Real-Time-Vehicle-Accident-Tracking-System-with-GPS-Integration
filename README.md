# Real-Time-Vehicle-Accident-Tracking-System-with-GPS-Integration

### Overview
This project utilizes Arduino, GPS, vibration sensors, and a modem to detect vehicle accidents and transmit location details via WhatsApp. When an accident occurs, the system automatically retrieves the vehicle's coordinates and sends them to a designated mobile number over the internet.

### How It Works
- When the system is powered on, an LED indicator confirms that the circuit is active.
- Vibration sensors detect obstacles or collisions and trigger an interrupt signal to the Arduino.
- The GPS module captures the vehicle’s real-time location upon detecting an accident.
- The modem facilitates communication by sending the GPS coordinates (latitude and longitude) via WhatsApp to a predefined mobile number.
- The recipient can use these coordinates to determine the exact accident location.
- The modem handles modulation during transmission and demodulation upon reception.
  
### Technologies Used
- Arduino (Microcontroller)
- GPS Module (Location tracking)
- Vibration Sensors (Accident detection)
- Modem (Data transmission via WhatsApp)
- Wi-Fi/Internet (Message delivery)
